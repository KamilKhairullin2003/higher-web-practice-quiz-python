# Quiz API

REST API для платформы создания викторин и управления вопросами. Проект реализован с полным изолированием бизнес-логики от слоя HTTP-представлений на базе трехслойной архитектуры (Controllers, Services/DAO, Models).

## 🛠 Технологии и стек
* **Язык и фреймворки:** Python, Django, Django REST Framework (DRF)
* **База данных:** SQLite
* **Тестирование:** Pytest, pytest-django
* **Линтеры:** Ruff

## 🚀 Ключевые особенности проекта
* **Трехслойная архитектура (Layered Architecture):** Вся бизнес-логика вынесена в изолированный сервисный слой (Services/DAO), контроллеры (APIView) остаются тонкими и отвечают только за маршрутизацию и HTTP-ответы.
* **Оптимизация базы данных:** Решена проблема `N+1` при сериализации графа связанных сущностей с помощью грамотного использования `select_related` и вложенных объектов `Prefetch`.
* **Продвинутая валидация:** Настроена строгая валидация сложных структур данных (хранение массивов в `JSONField`) как на уровне сериализаторов DRF, так и на уровне моделей базы данных.
* **Unit-тестирование:** Бизнес-логика сервисов и эндпоинты API покрыты изолированными автотестами.

## ⚙️ Установка и запуск

1. Клонируйте репозиторий и перейдите в директорию проекта:
   ```bash
   git clone <ссылка-на-репозиторий>
   cd <папка-проекта>
   ```

2. Установите зависимости (рекомендуется использовать uv для быстрого старта):
   ```bash
   uv sync
   ```
   Либо классическим способом через pip:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Выполните миграции базы данных:
   ```bash
   python manage.py makemigrations quiz
   python manage.py migrate
   ```

4. Запустите локальный сервер разработки:
   ```bash
   python manage.py runserver
   ```

## 🧪 Запуск тестов и линтера
Для прогона unit-тестов и проверки качества кода выполните:
```bash
uv run pytest
uv run ruff check ./quiz
```
